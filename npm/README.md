# lezx-code

Instala o [Lezx Code](https://github.com/Jvictorifran/LezxCode), uma IDE leve para desenvolvimento web (macOS e Windows), e o comando `lezx`.

```bash
npm install -g lezx-code
lezx .            # abre a pasta atual (na primeira vez, baixa e instala o app)
lezx index.html   # abre um arquivo
lezx --update     # reinstala o app na versão do pacote
lezx --help
```

O app é baixado das [Releases do GitHub](https://github.com/Jvictorifran/LezxCode/releases): no macOS, a versão certa para Apple Silicon ou Intel; no Windows, o instalador de 64 bits.
